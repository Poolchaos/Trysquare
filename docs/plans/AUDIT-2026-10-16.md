## 3. Windows portability (W)

| ID | Finding | Proof |
| --- | --- | --- |
| W1 | The CLI cannot be launched. `headless.ts:83` and `probe.ts:92,143` default to a bare `"claude"`, spawned without a shell. Measured: bare name gives ENOENT, a `.cmd` path throws EINVAL synchronously, a `.mjs` path throws EFTYPE synchronously. The bundled `.exe` path embeds the extension version and breaks on update. | Ran |
| W2 | `--system-prompt` rides in argv (`command.ts:63-64`). Windows caps a command line at 32,767 characters: a 40,000-character argument threw ENAMETOOLONG, 30,000 passed. | W4 | `gitops/run.ts:51` sets `GIT_CONFIG_NOSYSTEM=1`. Git for Windows keeps `credential.helper=manager` in system config, and under NOSYSTEM `git config --get credential.helper` exits 1, so a private HTTPS clone has no helper. The same setting drops system `core.autocrlf=true`, which is the wanted effect. | Ran |
| W5 | Install fails on npm 10.9.2 (section 2). The root cause of npm running node-gyp despite `"gypfile": false` in the package was not established. npm 11 was not tried. | Ran |

## 9. Cross-check against `AUDIT-2026-10-16-GLM.md`

Agreed and independently confirmed: W1 to W6, S1 structure, S2 counts, E4 to
E8, A1 to A6, U1 to U4, T2, T3 causes, T5, D1, the 41 e2e count, the five
unit failure causes.

Disagreements, each re-run or re-read on 2026-10-16:

1. **T1.** GLM reports CAUGHT. Reproduced as missed through verify.sh's own
   `run()` (section 8). The flaw is real on this machine's bash. Linux is
   not proven by this session either; a CI run settles it.
2. **`file://` URLs from backslash paths.** GLM calls them malformed and a
   cause of demo and e2e failure. `git clone --bare file://C:\...\src`
   succeeded under git 2.50 with `GIT_CONFIG_NOSYSTEM=1`. They are untidy,
   not a failure. The demo fails earlier, on W7, which GLM does not list.
3. **"The construction work is done"** (GLM section 2) is contradicted by
   GLM's own section 7 (D-51, T19) and by U1 to U7.
4. **"The critical advisory's affected range ends at 16.3.7."** The two
   critical ranges are `<16.3.3` and one `<16.3.6`; `16.3.8` is where every
   next advisory clears. Whether the Windows-hosted RCE applies is not open:
   the server here is Windows-hosted and listens on `::`.
5. **"No skipped tests"** (GLM section 9). `real-cli.test.ts:43` is a
   `describe.skipIf` with six tests; here 178 tests skip.
6. **G3 evidence "predates only df94bb0".** c09b2ad (2026-08-25 11:44)
   wrote the G3 row citing `review/2026-08-18-*` and an e2e run dated
   2026-08-18, in the same commit that changed
   `src/app/api/reviews/attention/route.ts`, `src/app/reviews/[id]/page.tsx`,
   `src/components/topbar.tsx` and `e2e/themes.spec.ts`. The e2e run the
   records cite predates both 2026-08-25 commits. GLM is right that c09b2ad
   re-shot the README images; `docs/images/dashboard.png` predates
   df94bb0's change to `src/app/page.tsx`. Read after both audits, with
   `gh`: CI run 33740537490 at df94bb0 (ubuntu-latest, 2026-09-03) passed
   `./verify.sh --build --e2e` with 726 unit tests, 6 skipped, and 41
   browser tests. So HEAD is e2e-green on Linux; only the records and the
   design screenshots lag it. A green run says nothing about T1, which
   only shows when an error marker is printed.
7. **SSE "frozen overstates".** Partly right: the poll keeps status moving.
   The feed and the request counter stop (U8).
8. **"Unverifiable: xhigh, the bundled binary's identity".** Both read here:
   `--version` prints `2.1.301 (Claude Code)`; `--help` lists xhigh (E9).
9. **EFTYPE "about 52 tests".** Measured 50 (T3).

Corrections to this session's first report: SQLite cleanup accounts for 196
